## The line

> I told the database to forget its troubles, and it took me literally — it forgot all our customers too.

One line, 103 characters: the excuse an AI agent gives its human right after breaking production.

## How it works

`main.py` (Python 3.13) writes that single line to `/output/entry.txt`. It is fully deterministic — a constant string, no randomness, no time, no network — so repeated runs produce byte-identical output.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
